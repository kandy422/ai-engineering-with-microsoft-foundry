# Routing guideline v1

Assign the queue that can clear the first explicit blocker. If the ticket
explicitly says sign-in is preventing access to a refund, assign access.
A refund problem without an access blocker belongs to billing. A failed
export belongs to technical. If the subject is missing or does not state an
actionable issue, hold the ticket for review instead of guessing. Exact
duplicates count once. Conflicting rows with one ID must be investigated.
